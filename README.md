# DreamPulse

Every night, a different world.

An experimental art and design project exploring how recorded sleep patterns might shape a private cinematic reflection. This public repository is a **prototype film and synthetic interactive showcase**, not a complete sleep-data integration or film-generation product.

## Public demonstration

The static website in `docs/` contains five curated, fictional scenarios. Original HTML/CSS compositions change with the selected scenario. All interactive fixture values are invented. The separately labeled prototype film uses real sleep data and is included under explicit owner permission. The interactive study does not reproduce an Apple Sleep Score; missing values stay unknown. Visual presets are artistic illustrations, not validated health categories or diagnoses.

## Local preview

Open `docs/index.html` in a browser. No installation, server, API key or build step is required. JavaScript enables the scenario selector.

## Public/private boundary

Public: website source, synthetic examples, original artwork, high-level roadmap, public documentation and the explicitly authorized `docs/media/dreampulse-2.1.mp4` film.

Private development is planned separately as `winglynn/dreampulse-private`; no automatic publication or shared Git history. Keep health records, other private videos, internal automation, prompts containing personal data and credentials out of this repository, including its history, issues and Discussions. Private GitHub storage is not a reason to commit credentials or raw health exports.

## Maintenance

Edit website copy in `docs/index.html`, appearance in `docs/style.css`, and synthetic scenarios in `docs/app.js`. Review every file and diff before committing. Follow the owner review guide supplied separately before each publication. Prefer a review branch and owner approval before merging to `main`, because merges redeploy Pages automatically.

The explicitly authorized film is hosted locally alongside the website. No external fonts, third-party media embeds, analytics, cookies, trackers, runtime dependencies, forms or health-data uploads are included. GitHub still processes hosting requests according to its policies.
